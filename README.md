# Square-Freee API Integration (Portfolio)

このプロジェクトは、**Square** および **freee** から取得したデータを用いて、  
指定された時間帯の各店舗ごとの**売上・人件費**を自動計算・集計するアプリケーションです。

## 📌 概要

- クライアントの要望により、**全コードの公開は行っておりません**。
- 本リポジトリは、**開発スキルを示すためのポートフォリオ**目的で一部構成のみを公開しています。
- 集計結果は、**LINE Messaging API** を使用し、LINE BOT を通じて通知されます。
- 関数は Google Apps Script (GAS) で記述され、**トリガーを用いた定刻実行**が可能です。

## 🛠️ 主な機能

- Square API から売上データの取得
- Freee API から労働時間・人件費の取得
- 各店舗の時間帯ごとの売上と人件費の自動集計
- LINE BOT による通知送信（Messaging API 使用）
- 指定時刻に実行される GAS トリガーの設定

## 🔒 注意事項

このリポジトリに含まれる情報は、クライアント案件の一部をポートフォリオとして抜粋したものであり、  
**機密性の高いコードやAPIキー等は一切含まれていません**。
